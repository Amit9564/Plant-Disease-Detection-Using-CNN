# Plant-Disease-Detection-Using-CNN
Plant Disease Detection and Prediction System using Convolution Neural Networks (CNN), TensorFlow, OpenCV, and Flask. The application helps identify plant diseases from leaf images and supports early diagnosis for improved agricultural productivity.
Plant Disease Detection Using CNN

Overview

Plant Disease Detection is a Deep Learning-based web application that identifies plant diseases from leaf images. The project uses a Convolutional Neural Network (CNN) trained on plant disease datasets to classify diseases accurately.

Features

- Upload plant leaf image
- Detect disease
- Display prediction result
- User-friendly interface
- Fast processing

Tech Stack

- Python
- TensorFlow
- OpenCV
- Flask
- HTML/CSS

Installation

pip install -r requirements.txt

python app.py

Future Scope

- Mobile Application
- Real-Time Disease Detection
- Multi-Language Support
- Farmer Recommendation System
